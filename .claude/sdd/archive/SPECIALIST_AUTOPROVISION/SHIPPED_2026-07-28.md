## Summary

AgentSpec's SDD workflow can now detect, before delegating implementation, that no specialist covers a task domain — and create that specialist just-in-time through the repo's own authoring SOPs. The `specialist-autoprovision` skill owns a citation-based availability sensor (a domain resolves only against a citable `routing.json` agent entry or a covering skill — no numeric confidence scores) and a provisioning sub-flow (component-model layer gate → `create-agent`/`create-skill` authoring → blocking hygiene grep → mandatory router regeneration → citation verification). `sdd-design` gained the primary sensor hook (Step 4.5), `sdd-build` a delegation safety net for design→build drift, and `sdd-autopilot` the Gate P policy row so autonomous runs resolve provisioning with proceed/retry/abort — never a human prompt. This closes the biggest silent-degradation path in intention-driven runs: work no longer falls to `(general)` execution unnoticed when a domain has no specialist.

## Lessons Learned

### Process

- The autonomous-brainstorm + human-ratification pattern worked end to end: the auto-generated BRAINSTORM carried `[ASSUMED]` flags with provenance, so the interactive session only had to ratify 3 decisions instead of redoing Phase 0 — direct evidence for the intention-driven direction this very feature generalizes.
- Verify counts against the disk before editing docs, never increment stated values: three separate count references (README plugin skills, docs/README totals, plugin/README commands) were already stale before this feature touched them; mechanical +1 would have produced three new wrong numbers.

### Technical

- The citation rule's skill-clause proved itself on its first contact: this feature's own manifest resolved every row to `(general)` + covering skills (`create-skill`, `component-model`), demonstrating that capability-shaped gaps must not spawn agents — the exact anti-sprawl behavior the sensor was designed to encode.
- A sanitization term list is itself private context: the hygiene grep caught the DESIGN document quoting the private terms it polices, which would have leaked them into the public repo. Committed artifacts must reference such lists abstractly; only ephemeral commands may name the terms.

### Communication

- One AskUserQuestion per fork, with option previews showing the concrete rule each choice implies (the match-semantics question), produced a decisive answer in one round — no follow-up clarification needed.

### Tools & Libraries

- `spec-lint --phase` as a per-phase contract gate caught nothing this run precisely because the templates were followed verbatim from the start — its value was making that conformance checkable rather than assumed.
- `generate-agent-router.py --check` as a drift sensor gave a free regression guarantee: zero drift confirmed the feature touched no agent frontmatter, exactly as designed.
